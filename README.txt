Rules:
1.) You can go on any slide that is not your own color,
you will bump all pawns of opponents
2.) You can only leave start with a 1,2, or a sorry card
3.) Both SORRY! and 11 swap, sorry only swaps from home,
11 only swaps from main
4.) If you get card 2, when you end turn it will automatically be your turn again,
where you then draw another card
5.) We were not able to disable endTurn if no move was available, user is not supposed to 
end without moving if a move is available (although user is prevented from moving multiple times)

To run the SORRY! game, you compile it and select number of players and pawns.
To move a pawn you click on it and hit move. To swap a pawn, you click on your desired pawn,
click move, then click on opponents pawn. For card 7, which you move 2 pawns, you click on the first pawn, 
hit move and select amount you want to move, then move second pawn.

Extra features:
We have added a game log, and the ability to select number of pawns for a shorter game.
